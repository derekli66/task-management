# Markdown format 1

`tasks.md` is the only authoritative session task document. Its document metadata fence records `format_version`, canonical `workspace`, `session_id`, `numbering_namespace`, `document_id` and `generation`; import metadata is optional. Task headings are generated labels, not independent fields. Scope metadata must match the call: copying a document to another workspace is not a supported transfer.

Each task has one `json task-management-task` fence. It contains all persisted fields except description, plus `description_length` (Unicode character count) and `integrity_digest`. After the exact `### 工作筆記` prefix, the reader consumes exactly that number of characters as ordinary Markdown description. This framing preserves embedded fences, headings, whitespace, CRLF, trailing newlines and delimiter-looking text without interpreting notes as structure.

The note body is followed by a generated `<details>` event-history section with a `json task-management-events` fence. Events store full before/after snapshots, actor, reason, evidence, original seq and revision. Historical snapshots are not normalized or expanded. Metadata and history JSON strings escape control characters; a fence-closing line cannot be introduced by an encoded string.

The integrity projection is documented in the approved plan. It excludes derived readiness and added scope fields. Events and integrity are validated independently; sparse imported snapshots do not prevent later updates. Invalid versions, duplicate identities, incomplete history, altered notes or malformed framing fail without resetting or rewriting a document.

Normal edits use MCP revision-controlled metadata/action updates. Reading Markdown directly is supported; arbitrary editing of length, integrity and history internals is not an alternative state-transition interface.

`numbering.md` and `activation.md` use a single `json task-management-metadata` fence. The latter's pending proposed-ledger snapshot supports deterministic cross-file recovery under the global numbering lock. Generated views state their source generation and are replaceable projections.
