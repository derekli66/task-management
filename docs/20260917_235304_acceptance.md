## Integration findings

1. This Codex build's legacy `.mcp.json` parser does not expand `${PLUGIN_ROOT}` in command arguments. A probe passed in direct SDK execution but failed in the host until `cwd: "."` explicitly anchored execution to the plugin cache and arguments used `./task_management/server.py`. The integration remained inside the approved plugin architecture.
2. This machine's default `python3` varies with cwd: the Godot project selected Python 3.13, whereas the new plugin directory initially selected Xcode Python 3.9. The setup script now rejects Python older than 3.13, and this installation used the explicit pyenv 3.13 interpreter.
3. A plain unparameterized `dict` return annotation did not produce structured output in the probe. The final tools explicitly return MCP CallToolResult with both text and structured content; tests compare them.

Runtime: Python 3.13.0, MCP SDK 2.2.0, Codex CLI 0.155.0-alpha.2.6. Exact direct/transitive runtime dependencies are in `requirements.lock` and installed outside the plugin cache. Startup does not install dependencies.
