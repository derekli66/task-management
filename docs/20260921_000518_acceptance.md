# Ready / Waiting reminder groups — acceptance summary

## Summary

Pending tasks now retain the existing actionable-first order while the compact
Hook and assistant summaries label that order explicitly:

```text
Ready
  ○ #1 First ready
  ○ #3 Third ready
Waiting
  ◌ #2 Second waiting — waiting
```

The display does not sort by task number. In-progress and blocked task behavior,
the database query, task schema, five-item bound, and zero-state message are
unchanged.
